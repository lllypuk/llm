# CI на последнем патче Go

## Overview

Go 1.27.3 и 1.26.10 (19.10.2026) закрывают CVE-2026-111943 в `crypto/x509`. Матрица CI `['1.26', '1.27']` без
`check-latest` берёт патч из кеша раннера GitHub и может гонять тесты на уязвимом. `go.mod` не меняется:
библиотека не навязывает потребителю патч, минимум держат сервисы.

## Context (from discovery)

- `.github/workflows/ci.yml`: `actions/setup-go@v6` с `go-version: ${{ matrix.go }}`, матрица `['1.26', '1.27']`.
- `go.mod` — `go 1.26`.

## Решения (приняты 2026-10-21, не переигрывать)

1. `check-latest: true` у `setup-go`; матрица и `go.mod` прежние.

## Development Approach

- **testing approach**: Regular; новых тестов нет.
- Задача закрывается `go vet ./... && go test -race ./...` и `go test -race -tags live ./cmd/llmcheck` под `GOTOOLCHAIN=go1.26.10` и
  `GOTOOLCHAIN=go1.27.3` — зелёные.
- Коммит `ci:`.
